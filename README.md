# Question-Generator

これは、計算問題（掛け算・割り算）を自動生成し、ユーザーに出題するGUIアプリケーションです。解答の正誤を記録し、間違えた問題は再度出題する機能も備えています。

## 主な機能

*   **計算問題の自動生成**: 掛け算または割り算の問題を生成します。
*   **GUIインターフェース**: `tkinter`を使用したシンプルなGUIで、問題に解答できます。
*   **設定のカスタマイズ**:
    *   問題の桁数
    *   初期問題数と最大問題数
    *   間違えた際の追加問題数
    *   問題の種類（掛け算/割り算）
*   **設定エディタ**: GUIで上記の設定を簡単に変更できます (`config_editor.py`)。
*   **解答履歴のロギング**: 解答結果（正解/不正解、問題、日時など）をJSON形式のログファイルに記録します。
*   **Notion連携（任意）**: Notionデータベースと連携し、解答履歴などを記録する機能（設定項目あり）。

## 動作要件

*   Python 3.x
*   Tkinter (Pythonの標準ライブラリ)

## 使用方法

### 1. 問題を解く

1.  リポジトリをクローンまたはダウンロードします。
2.  ターミナルで`Question-Generator`ディレクトリに移動します。
3.  以下のコマンドを実行して、問題生成・出題アプリケーションを起動します。

    ```bash
    python Question.py
    ```

4.  表示される問題に対して、解答を入力しEnterキーを押してください。

### 2. 設定を変更する

設定は`config_editor.py`を実行することで、GUI上から編集できます。

1.  ターミナルで以下のコマンドを実行します。

    ```bash
    python config_editor.py
    ```

2.  設定項目を編集し、「保存」ボタンをクリックすると、`ログ・設定/config.json`に設定が保存されます。

## 設定ファイル

設定は`ログ・設定/config.json`にJSON形式で保存されます。各項目の意味は以下の通りです。

*   `NOTION_API_KEY`: （任意）Notion APIのAPIキー。
*   `DATABASE_ID`: （任意）連携するNotionデータベースのID。
*   `LOG_FILE`: 解答履歴を保存するログファイルのパス。
*   `DEBUG`: デバッグモードの有効/無効。
*   `NUM_DIGITS`: 問題に出題される数値の桁数。
*   `ADD_QUESTIONS_ON_MISTAKE`: 1問間違えるごとに追加される問題の数。
*   `NUM_QUESTIONS`: アプリケーション起動時の初期問題数。
*   `MAX_QUESTIONS`: 追加問題を含めた最大の問題数。
*   `TYPE`: 出題する問題の種類 (`掛け算`または`割り算`)。

## ログファイル

解答ごとの詳細な履歴が、設定ファイルで指定された`LOG_FILE`（デフォルトでは`ログ・設定/log.json`）に追記されていきます。ログには以下の情報が含まれます。

*   タイムスタンプ
*   出題された問題
*   正解の答え
*   正解したかどうか
*   問題の種類と桁数
